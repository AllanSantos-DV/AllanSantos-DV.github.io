like-move

Mantém o Windows acordado com um movimento imperceptível do mouse, só quando você quer.

O que é

Um programa na bandeja do Windows que move o mouse de forma imperceptível para a tela não dormir: parado, atrás de um KVM ou sempre. Em Wi-Fi público, deixa a tela bloquear.

Para quê

Manter uma sessão remota ou uma apresentação ativa sem a tela bloquear, em casa ou no trabalho, e continuar seguro fora das suas redes.

Por que foi feito

Tela que bloqueia no meio de uma sessão atrapalha; em rede pública, bloquear é a atitude segura. O like-move distingue as duas situações.
