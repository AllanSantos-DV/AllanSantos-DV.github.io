Client Harness

Faz o Claude Code e o Codex seguirem o padrão de cada cliente: confere cada ação antes de o agente escrever e recusa com o motivo.

O que é

Um daemon local que confere cada ação do Claude Code e do Codex contra as regras do cliente da pasta onde você está. Se a ação foge do padrão, ele recusa na hora e diz o que usar no lugar; se não, deixa passar.

Para quê

Atender mais de um cliente com agentes de código sem que um padrão vaze para o outro: caminhos que não se tocam, bibliotecas que não entram, comandos que não rodam.

Por que foi feito

Pedir o padrão no prompt falha em silêncio: o agente esquece no meio da tarefa, a revisão pega tarde e o retrabalho volta para você. Como regra, o padrão é conferido antes de cada ação.
