Claude Code Boss

Plugin do Claude Code com memória de projeto, execução curada de comandos e rota própria de modelos.

O que é

Um plugin para o Claude Code Desktop com base de conhecimento semântica local, execução curada de comandos que não enche o contexto, aprendizado dentro do próprio trabalho e, se você quiser, o MCP Memory como base.

Para quê

Fazer o Claude Code lembrar do projeto entre sessões e gastar menos contexto com a saída dos comandos.

Por que foi feito

O Claude Code nativo não guarda o que aprendeu entre sessões nem filtra saídas longas; o Boss cobre essas duas lacunas.
