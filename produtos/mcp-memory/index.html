MCP Memory Server

Uma memória por projeto, compartilhada por todas as suas ferramentas de IA.

O que é

O servidor que guarda o que os seus agentes aprendem em cada projeto, como decisões, convenções e skills, e a cada pergunta entrega só o que é relevante. Quando nada serve, devolve vazio em vez de inventar contexto.

Para quê

Trocar do Copilot para o Claude Code, o Codex ou o OpenCode sem reensinar o projeto, e manter uma equipe inteira na mesma memória, num servidor próprio.

Por que foi feito

Quando cada ferramenta guarda a própria memória, você reensina tudo a cada troca. Com um servidor no meio, o que foi aprendido num lugar vale em todos.

4ferramentas conectadas: Copilot, Claude Code, Codex e OpenCode
5blocos de lembrança por pergunta
2bancos: SQLite local ou PostgreSQL para equipe
