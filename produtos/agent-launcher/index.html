Agentes de IAnpm

Agent Launcher

Abre Claude Code, Codex e Copilot nos seus projetos, ligados ao provedor de modelos que você escolher.

O que é

Um app para Windows que abre o Claude Code, o Codex e o Copilot CLI em cada projeto, ligados ao seu proxy, roteador ou API. A lista de modelos vem do próprio provedor, e cada sessão recebe só o que ele confirma.

Para quê

Trocar de provedor ou de cliente sem editar arquivo de configuração: um perfil por cliente, a última conexão de cada projeto lembrada, retomada de conversas e o uso do mês por modelo.

Por que foi feito

Quem atende empresas diferentes usa a IA autorizada de cada uma. Configurar cada agente à mão, projeto a projeto, é lento e arrisca vazar chave; o launcher cifra as chaves no Windows e entrega tudo só no ambiente de cada sessão.
