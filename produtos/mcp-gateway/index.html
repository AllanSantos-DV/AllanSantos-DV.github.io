MCP Gateway

Um endpoint para todos os seus servidores MCP, compartilhado por todas as sessões.

O que é

Um agregador MCP que conecta uma vez em cada servidor e reexpõe todas as ferramentas num endpoint local único, compartilhado por várias sessões e vários agentes.

Para quê

Parar de multiplicar processos: cinco sessões com quatro servidores deixam de ser vinte instâncias.

Por que foi feito

No Windows, um servidor iniciado por npx vira quatro processos, e cada sessão cria os seus. O gateway mantém uma única cópia de tudo.

6processos atendem 5 sessões, no lugar de 20 instâncias
1endpoint para todos os servidores
