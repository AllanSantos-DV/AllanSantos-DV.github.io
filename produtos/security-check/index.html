Security Check

Auditoria de segurança e de LGPD de repositórios, dentro do Copilot Chat do VS Code.

O que é

Uma extensão do VS Code com sete verificadores (segredos, padrões de código perigosos, permissões, arquivos, rede, LGPD e dependências), um participante de chat @security-check e uma nota de 0 a 100.

Para quê

Auditar um repositório antes de publicar, ver o que importa primeiro e dispensar de forma persistente o que já foi avaliado.

Por que foi feito

Segredo no código e dado pessoal sem consentimento são problemas que se acham mais barato antes da publicação.
