local-ci-forge

Transforma o seu Windows com WSL em runners do GitHub Actions, sem o teto de minutos do mês.

O que é

Um kit que faz de uma estação Windows 11 uma frota de runners do GitHub Actions, no Windows e no Linux do WSL, e leva os jobs de cada repositório para ela com uma única variável.

Para quê

Rodar os mesmos workflows e releases sem gastar a cota mensal de minutos do GitHub, e voltar para a nuvem com uma variável.

Por que foi feito

Em repositório privado, os minutos do GitHub saem de uma cota mensal; quando ela acaba, CI, CD e releases param.
