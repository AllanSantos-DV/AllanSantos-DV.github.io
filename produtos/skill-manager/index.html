Skill Manager

Sincroniza skills, agents e hooks do Copilot a partir de vários repositórios Git.

O que é

Uma extensão do VS Code que instala e mantém skills, agents e hooks do GitHub Copilot vindos de quantos repositórios Git você quiser, públicos ou privados, com sincronização automática e prioridade configurável.

Para quê

Dar a uma equipe o mesmo conjunto de habilidades do agente, sempre atualizado, e propor melhorias de volta ao repositório sem perder o que você editou localmente.

Por que foi feito

Skills espalhadas em pastas viram cópias desatualizadas. O Skill Manager detecta a divergência e preserva a edição local no próximo sincronismo.
