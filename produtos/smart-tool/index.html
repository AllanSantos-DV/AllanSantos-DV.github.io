Smart Tool

Um servidor local que dá ao agente busca de código e de web mais precisas e mais baratas.

O que é

Um servidor MCP local com quatro ferramentas: busca semântica e exata no código do projeto, busca na web em vários idiomas, leitura de página que devolve só a resposta e um painel do índice do projeto.

Para quê

Fazer o Claude Code e o Codex acharem o trecho certo sem ler dezenas de arquivos, e pesquisar na web sem despejar páginas inteiras na conversa.

Por que foi feito

As buscas embutidas gastam muito contexto com resultado que não serve. Aqui os resultados vêm separados em código, testes e documentação, e a leitura de página é resumida por um modelo pequeno.

4ferramentas: código, web, leitura de página e projeto
3blocos de resultado: código, testes e documentação
24 hde cache das páginas lidas
